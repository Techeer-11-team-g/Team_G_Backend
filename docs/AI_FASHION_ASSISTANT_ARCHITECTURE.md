## 1. 현재 서비스 요약

### 1.1 핵심 아키텍처

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         현재 서비스 파이프라인                            │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  [사용자 이미지 업로드]                                                   │
```

### 1.2 기술 스택

| 구분          | 기술                                                  |
| ------------- | ----------------------------------------------------- |
| Framework     | Django 4.2 + Django REST Framework                    |
| Async Jobs    | Celery + Redis (3 queues: default, analysis, fitting) |
| Vector Search | OpenSearch k-NN (HNSW, 512-dim, cosine)               |
| Embeddings    | Marqo-FashionCLIP                                     |
| LLM           | OpenAI GPT-4o-mini, Claude Sonnet/Haiku               |
| Storage       | Google Cloud Storage                                  |
| Database      | MySQL                                                 |
| Monitoring    | OpenTelemetry, Prometheus, Loki                       |

### 1.3 현재 기능

| 기능            | 설명                                                  | 엔드포인트                    |
| --------------- | ----------------------------------------------------- | ----------------------------- |
| **이미지 분석** | 업로드된 이미지에서 패션 아이템 감지 → 유사 상품 검색 | `POST /api/v1/analyses`       |
| **Refine**      | 자연어로 검색 결과 재조정                             | `PATCH /api/v1/analyses`      |
| **가상 피팅**   | 사용자 전신 사진 + 상품 → 가상 착용 이미지            | `POST /api/v1/fitting-images` |
| **장바구니**    | 상품 담기/제거                                        | `CartItem` 모델               |
| **주문**        | 장바구니 → 주문 생성                                  | `POST /api/v1/orders`         |

### 1.5 현재 한계점

| 한계                  | 설명                                  |
| --------------------- | ------------------------------------- |
| 이미지 분석 선행 필수 | Refine은 이미지 분석 후에만 사용 가능 |
| 텍스트 전용 입력      | 추가 참조 이미지 입력 불가            |
| 단일 세션 컨텍스트    | 분석 ID 내에서만 대화 유지 (24h TTL)  |
| 기능 분리             | 검색/피팅/구매가 별도 플로우          |
| 사이즈 미연동         | 사용자 정보 기반 사이즈 추천 없음     |

## 2. 확장 비전: AI 패션 어시스턴트

### 2.1 목표

**"자연어와 이미지로 대화하며 쇼핑하는 AI 어시스턴트"**

- 이미지 + 자연어 복합 입력 지원
- 검색 → 피팅 → 사이즈 추천 → 구매까지 단일 대화 플로우
- 사용자 맞춤 개인화

### 2.2 신규 아키텍처

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                     AI 패션 어시스턴트 (메인 에이전트)                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   [사용자 입력]                                                                │
│   ├─ 자연어: "검은색 구두 찾아줘"                                                  │
│   ├─ 이미지: 참조 이미지 첨부                                                     │
│   └─ 복합: "이 이사진에서 유사한 상품 찾아줘" + 이미지                                 │
│         │                                                                   │
│         ▼                                                                   │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │                    🧠 메인 에이전트 (Orchestrator)                      │   │
│   │                                                                     │   │
│   │  Intent 분석 → 서브 에이전트 라우팅 → 결과 통합 → 응답 생성                    │   │
│   │                                                                     │   │
│   └───────────────────────────┬─────────────────────────────────────────┘   │
│                               │                                             │
│         ┌─────────────────────┼─────────────────────┐                       │
│         ▼                     ▼                     ▼                       │
│   ┌───────────┐        ┌───────────┐        ┌───────────┐                   │
│   │ 🔍 Search │        │ 👔 Fitting│        │ 🛒 Commerce│                   │
│   │   Agent   │        │   Agent   │        │   Agent   │                   │
│   └─────┬─────┘        └─────┬─────┘        └─────┬─────┘                   │
│         │                    │                    │                         │
│   ┌─────┴─────┐        ┌─────┴─────┐        ┌─────┴─────┐                   │
│   │이미지 분석│        │가상 피팅  │        │사이즈 추천│                           │
│   │유사도 검색│        │착장 비교  │        │장바구니   │                           │
│   │속성 필터링│        │스타일 매칭│        │주문/결제  │                           │
│   │크로스 추천│        │컬러 분석  │        │가격 비교  │                          │
│   └───────────┘        └───────────┘        └───────────┘                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.3 핵심 차별점

| 기존                        | 신규                    |
| --------------------------- | ----------------------- |
| 이미지 업로드 → 분석 → 결과 | 자연어 대화로 시작 가능 |
| 단일 기능 API 호출          | 통합 대화 인터페이스    |
| 수동 플로우 전환            | 자동 Intent 라우팅      |
| 고정된 필터 옵션            | 자연어 필터링           |
| 기능별 분리된 UX            | 연속적인 대화 경험      |

## 3. 서브 에이전트 설계

### 3.1 Search Agent (검색 에이전트)

#### 역할

이미지/텍스트 기반 상품 검색 및 매칭

#### 입력

```yaml
image: bytes | null # 참조 이미지 (선택)
query: string # 자연어 쿼리
context:
  previous_results: list # 이전 검색 결과
  user_preferences: dict # 사용자 선호도
  session_state: dict # 현재 세션 상태
```

#### 기능

**1. 이미지 분석**

- 객체 감지 (Google Vision API)
- 속성 추출 (Claude Vision)
- 임베딩 생성 (FashionCLIP 512-dim)

**2. 유사도 검색**

- k-NN 벡터 검색 (OpenSearch)
- 하이브리드 필터링 (색상, 브랜드, 스타일, 소재)
- Claude 리랭킹

**3. 크로스 카테고리 추천**

- "이 상의와 어울리는 하의"
- "비슷하지만 다른 브랜드"
- "더 저렴한 대안"

**4. 컨텍스트 기반 검색**

- 이전 대화 참조
- 사용자 선호도 반영
- 제외 상품 필터링

#### 출력

```yaml
products: list[Product] # 매칭 상품 리스트
match_reasons: list[string] # 매칭 이유 설명
recommendations: list[Product] # 추가 추천 상품
search_metadata:
  total_candidates: int
  filters_applied: list
  embedding_source: string # image | text | hybrid
```

#### 트리거 키워드

```
찾아줘, 보여줘, 검색, 추천, 비슷한, 어울리는, ~있어?, ~없어?
```

### 3.2 Fitting Agent (피팅 에이전트)

#### 역할

가상 피팅 및 스타일 시뮬레이션

#### 입력

```yaml
user_image: bytes | url # 사용자 전신 이미지
products: list[Product] # 착용할 상품 목록
style_request: string # 스타일 요청 (선택)
compare_mode: boolean # 비교 모드 여부
```

#### 기능

**1. 단일 피팅**

- 상품 1개 가상 착용
- The New Black API 활용
- 카테고리별 엔드포인트 (vto, vto-shoes, vto-bag)

**2. 코디 피팅 (신규)**

- 상의 + 하의 + 신발 조합 피팅
- 전체 아웃핏 시뮬레이션
- 순차 합성 또는 배치 요청

**3. 스타일 비교 (신규)**

- 여러 옵션 나란히 비교
- "A 바지 vs B 바지 어때?"
- 그리드 레이아웃 결과

**4. 컬러 매칭 분석 (신규)**

- 색상 조화 점수 (0-100)
- 보색/유사색 분석
- 개선 제안

#### 출력

```yaml
fitting_images: list[FittingResult]
  - image_url: string
  - product: Product
  - status: string
style_analysis:
  color_harmony_score: int
  style_match_score: int
  suggestions: list[string]
alternatives: list[Product]
```

#### 트리거 키워드

```
입어볼래, 피팅, 착용, 어떻게 보여?, 비교, vs, 어울려?
```

### 3.3 Commerce Agent (커머스 에이전트)

#### 역할

사이즈 추천, 장바구니 관리, 구매 지원

#### 입력

```yaml
user_info:
  height: int # cm
  weight: int # kg
  preferred_fit: string # slim, regular, oversized
  size_history: list # 과거 구매 사이즈
product: Product # 대상 상품
action: string # size_recommend | cart_add | cart_remove | order
quantity: int # 수량
```

#### 기능

**1. 사이즈 추천**

- 사용자 신체 정보 기반 매칭
- 브랜드별 사이즈 가이드 참조
- 구매 이력 기반 보정
- 신뢰도 점수 제공

**2. 장바구니 관리**

- "이거 장바구니에 담아줘"
- "장바구니에서 바지 빼줘"
- "장바구니 보여줘"
- 수량 변경

**3. 주문 지원**

- 장바구니 → 주문 전환
- 배송지 확인/변경
- 주문 상태 조회
- 주문 취소

**4. 가격 정보 (신규)**

- 현재 가격 확인
- 할인/쿠폰 정보
- 가격 변동 알림

#### 출력

```yaml
size_recommendation:
  recommended_size: string
  confidence: float
  alternatives: list
  reasoning: string
cart_status:
  items: list[CartItem]
  total_price: int
  item_count: int
order_status:
  order_id: string
  status: string
  tracking: string
```

#### 트리거 키워드

```
사이즈, 담아줘, 장바구니, 주문, 구매, 결제, 몇 사이즈, 배송
```

## 4. 메인 에이전트 (Orchestrator)

### 4.1 역할

사용자 의도 파악 및 서브 에이전트 조율

### 4.2 Intent Classification

```python
INTENT_CATEGORIES = {
    "search": {
        "keywords": ["찾아", "보여", "검색", "추천", "비슷한", "어울리는"],
        "patterns": ["~있어?", "~없어?", "~어때?"],
        "with_image": True  # 이미지만 전송해도 검색 의도
    },
    "fitting": {
        "keywords": ["입어", "피팅", "착용", "어떻게 보여", "비교"],
        "patterns": ["~입어볼래", "~vs~", "~어울려?"]
    },
    "commerce": {
        "keywords": ["사이즈", "담아", "장바구니", "주문", "구매", "결제"],
        "patterns": ["몇 사이즈", "~담을래", "~살래"]
    },
    "compound": {
        "patterns": ["~하고 ~해줘", "괜찮으면 담아", "입어보고 주문"]
    }
}
```

### 4.3 처리 플로우

```
┌─────────────────────────────────────────────────────────────────┐
│                      Orchestrator Flow                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. Input Processing                                            │
│     ├─ 텍스트 추출                                               │
│     ├─ 이미지 감지                                               │
│     └─ 세션 컨텍스트 로드                                         │
│                                                                 │
│  2. Intent Classification                                       │
│     ├─ 키워드 매칭                                               │
│     ├─ 패턴 분석                                                 │
│     ├─ 컨텍스트 참조                                             │
│     └─ 복합 의도 분해                                            │
│                                                                 │
│  3. Agent Routing                                               │
│     ├─ 단일: 해당 에이전트 호출                                   │
│     ├─ 병렬: 동시 호출 (검색 + 피팅)                              │
│     └─ 순차: 체인 호출 (검색 → 피팅 → 장바구니)                    │
│                                                                 │
│  4. Result Aggregation                                          │
│     ├─ 결과 통합                                                 │
│     ├─ 충돌 해결                                                 │
│     └─ 우선순위 정렬                                             │
│                                                                 │
│  5. Response Generation                                         │
│     ├─ 자연어 응답 생성                                          │
│     ├─ 상품/이미지 첨부                                          │
│     ├─ 후속 액션 제안                                            │
│     └─ 세션 상태 업데이트                                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.4 Context Management

```python
class SessionContext:
    """세션 상태 관리"""

    session_id: str
    user_id: int

    # 대화 히스토리
    conversation_history: list[Message]  # role, content, timestamp

    # 현재 상태
    current_search_results: list[Product]
    selected_products: list[Product]
    fitting_results: list[FittingImage]

    # 사용자 정보
    user_profile: UserProfile
    user_preferences: UserPreferences

    # 메타데이터
    created_at: datetime
    last_activity: datetime
    ttl: int = 3600 * 24  # 24시간
```

### 4.5 Agent Routing Rules

| 시나리오                               | 라우팅                                      |
| -------------------------------------- | ------------------------------------------- |
| 이미지만 전송                          | Search Agent                                |
| "찾아줘" + 이미지                      | Search Agent                                |
| "입어볼래"                             | Fitting Agent (current_search_results 필요) |
| "이거 담아줘"                          | Commerce Agent                              |
| "사이즈 뭐가 좋아?"                    | Commerce Agent                              |
| "찾아서 입어봐"                        | Search → Fitting (순차)                     |
| "입어보고 담아줘"                      | Fitting → Commerce (순차)                   |
| "이거랑 어울리는 바지 찾아서 비교해줘" | Search → Fitting (순차)                     |

## 5. 대화 시나리오

### 5.1 시나리오 1: 이미지 + 자연어 복합 요청

```
┌─────────────────────────────────────────────────────────────────┐
│ 이미지 기반 크로스 카테고리 검색 → 피팅 → 구매                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│ 👤 [셔츠 이미지 첨부] "이거랑 어울리는 바지 찾아줘"               │
```

### 6.3 서비스 클래스 구조

```python
# services/agent/orchestrator.py
class OrchestratorAgent:
    """메인 에이전트 - 의도 분류 및 라우팅"""

    def __init__(self):
        self.search_agent = SearchAgent()
        self.fitting_agent = FittingAgent()
        self.commerce_agent = CommerceAgent()
        self.intent_classifier = IntentClassifier()

    async def process(
        self,
        session_id: str,
        message: str,
        images: list[bytes] = None,
        context: dict = None
    ) -> AgentResponse:
        # 1. 세션 로드
        session = await self.load_session(session_id)

        # 2. 의도 분류
        intent = await self.intent_classifier.classify(
            message=message,
            has_image=bool(images),
            context=session.context
        )

        # 3. 에이전트 라우팅
        result = await self.route_to_agents(intent, session, message, images)

        # 4. 응답 생성
        response = await self.generate_response(result, session)

        # 5. 세션 업데이트
        await self.update_session(session, message, response)

        return response
```

```python
# chat/models.py

class ChatSession(models.Model):
    """AI 어시스턴트 대화 세션"""

    id = models.UUIDField(primary_key=True, default=uuid.uuid4)
    user = models.ForeignKey(User, on_delete=models.CASCADE, related_name='chat_sessions')

    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)
    ended_at = models.DateTimeField(null=True, blank=True)

    # 세션 메타데이터
    message_count = models.PositiveIntegerField(default=0)
    agents_used = models.JSONField(default=list)  # ["search", "fitting", "commerce"]

    # 결과 요약
    products_viewed = models.PositiveIntegerField(default=0)
    products_fitted = models.PositiveIntegerField(default=0)
    products_carted = models.PositiveIntegerField(default=0)
    products_ordered = models.PositiveIntegerField(default=0)

    class Meta:
        indexes = [
            models.Index(fields=['user', '-created_at']),
        ]


class ChatMessage(models.Model):
    """대화 메시지"""

    session = models.ForeignKey(ChatSession, on_delete=models.CASCADE, related_name='messages')

    role = models.CharField(max_length=20, choices=[
        ('user', 'User'),
        ('assistant', 'Assistant'),
        ('system', 'System'),
    ])
    content = models.TextField()

    # 첨부 데이터
    images = models.JSONField(default=list, blank=True)  # 이미지 URL 리스트
    products = models.JSONField(default=list, blank=True)  # 응답에 포함된 상품
    fitting_results = models.JSONField(default=list, blank=True)  # 피팅 결과

    # 메타데이터
    intent = models.CharField(max_length=50, blank=True)  # 분류된 의도
    agent_used = models.CharField(max_length=50, blank=True)  # 사용된 에이전트
    processing_time_ms = models.PositiveIntegerField(null=True)

    created_at = models.DateTimeField(auto_now_add=True)

    class Meta:
        ordering = ['created_at']
```
